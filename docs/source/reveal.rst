Reveal Module
=============

The ``reveal`` module provides high-level interfaces for creating comprehensive analysis figures and visualizations using the AtlasReveal class.

Module Overview
----------------

This module includes:
* Comprehensive figure generation for electrophysiological data
* Multi-panel visualization layouts
* Feature visualization with histology integration
* Classifier result visualization
* Quality control and data validation plots
