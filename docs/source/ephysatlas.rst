ephysatlas Package
==================

The ``ephysatlas`` package is the core module of ibleatools, providing comprehensive tools for electrophysiological data analysis and visualization.

Package Overview
-----------------

The ephysatlas package is organized into several specialized modules:

* **features**: Feature extraction and computation from electrophysiological data
* **plots**: Visualization tools for data analysis and publication
* **reveal**: High-level interface for creating comprehensive analysis figures
* **utils**: Utility functions for data management and file operations
* **anatomy**: Brain region classification and atlas functionality
* **regionclassifier**: Machine learning models for brain region prediction
* **data**: Data loading and management utilities
