Overview
---------

These guides are based on the example scripts in the ``examples/`` directory of the repository. Each guide provides:

* **Prerequisites**: What you need to have installed or set up
* **Step-by-step instructions**: Detailed walkthrough of the process
* **Code examples**: Complete working examples you can copy and modify
* **Expected output**: What you should see when the script runs successfully
* **Troubleshooting**: Common issues and how to resolve them

The examples cover the most common use cases for ibleatools, from basic feature extraction to advanced analysis workflows.
